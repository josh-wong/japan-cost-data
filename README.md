# japan-cost-data

Versioned JSON data files derived from official Japanese government statistics. The files are generated by automated workflows and published as static content. Please do not edit them by hand.

## Sources and credit

The data is derived from statistics published by the Statistics Bureau of Japan (総務省統計局) through e-Stat (政府統計の総合窓口). Each file names its source. The values are processed, and the processing is not done by the government.

出典：「小売物価統計調査結果」（総務省統計局）、「家計調査結果」（総務省統計局）を加工して作成
